# 复盘与用时

开始：2026-11-06 17:07（Asia/Shanghai）。至17:47真实模型、真实网页、数字事实边界与本地63项测试、25项浏览器检查完成，约40分钟；随后最终提交与CI收尾，结束时间见交付记录与Git/Actions。用时包括模型推理、调试、测试与等待，不是用户独立编码时长。

重点困难：引用 ID 不等于事实支持；编辑后检查不能复用旧版；逐镜头语音与画面时间必须一致；失败和超长不能被一句“完成”掩盖。

事实处理采用保守的原文组合。与任意同义改写相比，这使审核可逐句对照，能明确拒绝“支持字幕”之外的80%效益推断。代价是创意有限、单条事实容易产生重复。下一步应在更丰富且经授权的事实库上评测创意质量，并把语义改写审核作为独立、可失败的环节。

首轮模型参数错误说明JSON合法不等于动作合法。JSON Schema减少格式问题，但没有解决循环估算旧稿；阶段工具约束才让模型在检查之后实际选择修订或停止。设计骨架可以是确定的，生成内容和修正策略仍需实际模型。真实38秒草稿被改成20秒，而Mock为28秒，清楚体现了这条边界。

空检索结果还需区分“全库没有资料”和“某次查询未命中”。补充工具实际库存数后，真实模型从重复16步改为2步请求补充。所有初次失败、开发者中止诊断与复测独立留存，避免靠覆盖日志制造稳定性。
