# 原型与痛点

交付 [可导入 Figma 的 SVG](prototypes/script-flow.svg) 与 [PNG 预览](prototypes/script-flow.png)，沿用用户确认的图稿方式，没有声称创建 Figma 在线文件。布局经过真实浏览器渲染与检查。

| 痛点 | 架构处理 | 额外验证 |
| --- | --- | --- |
| 缺输入被模型默认补齐 | 入口验证五项创作要求 | 缺各字段、空白、非法时长 |
| 空检索后编造内容 | 检索为空由模型选择改词或请求资料 | 空→空、空→有结果、初稿无引用来源 |
| 虚假事实附合法 ID | source_id + fact_id + 精确事实文本检查 | 无依据80%、否定、额外功能、零宽字符、伪来源 |
| 时长只按模型自报 | 旁白与画面取较大值，逐镜头相加 | 38→28/20、0.1秒伪停留、语速变化、转场、精确边界 |
| 编辑后沿用旧检查 | 脚本版本与 hash 绑定 | 未提交编辑提示、提交后双检查、错误改稿不静默修正 |
| 工具失败冒充通过 | 清除相应检查，保留草稿 | 检索/估算/规则故障、跨进程恢复 |
| 模型重复无效工具 | JSON Schema + 按阶段开放动作 + 总步数上限 | 初次失败原始记录、阶段动作边界、不可行终止 |

阶段约束只限制当前有哪些合法动作，不生成查询、不生成修订内容，也不将固定分支伪装为模型。关键决策由实际模型产生：怎样检索、保留哪些镜头、如何调整秒数、要修正还是明确停止。
