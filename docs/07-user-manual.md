# 使用手册

启动：仓库目录运行 `py -3.10 -m src.web`，打开 http://127.0.0.1:8769/ 。网页手册 http://127.0.0.1:8769/manual.html。端点 `http://localhost:11434/v1` 是模型 API，直接打开可能404；它不是工作台。

## 创作与检查

1. 选择场景，填写主题、受众、平台、目标时长和风格。时间是硬上限，单位秒；不要求填满。默认品牌支持抖音、小红书、视频号、B站；风格为简洁、活泼、沉稳。
2. 初次可用离线演练。真实模式使用本机 Ollama `qwen2.5:7b-instruct`，无需 Key。CPU 推理可需数分钟；单次模型请求90秒、默认整个任务16步。
3. 点击“生成 / 优化脚本”。右侧逐镜头展示画面、旁白/字幕、source_id/fact_id、画面停留与旁白估算、起止时间、原文支持状态。展开来源查看实际事实。
4. 只有当前版本时长与规则检查都通过，脚本才显示已复查。任务已完成还要求模型正确结束；达到上限或模型失败时，脚本检查状态仍单独显示。
5. 导出记录保存请求、素材/规则、生成脚本、检查、修订历史及 Trace。字幕直接复用已检查的旁白，避免有另一份未核验文字。

## 编辑不会隐式触发模型改写

展开“编辑脚本并重新检查”，修改 JSON 中标题、镜头顺序、旁白、来源、画面说明或秒数。输入期间提示“尚未检查”，上方结果仍属于上次提交版本。

点击“检查我的修改”会建立新的编辑任务，只运行确定性的检索、估算和规则工具，结果 mode=review，不调用模型润色。这样可以真实看到用户修改是否违反规则。若草稿未通过，点击“让 Agent 继续处理”才由选定的 Mock/真实模式针对检查结果修订。

例如把旁白改成“效率提升80%”，即使保留 P01/F01 也会失败，因为资料仅有“支持字幕”。当前策略允许事实原文组合，仅忽略汉字之间空白及有限句末陈述/感叹标点，保留英文词边界、句内标点、问号和单位上标；其他改写要提供新资料或按风险提示修正。标题和画面说明应采用品牌规则许可短语。旧版本已通过的脚本再次执行时，会按当前检查策略重新核验。

## 参考场景

| 场景 | 可核查行为 |
| --- | --- |
| 正常30秒 | 检索来源、生成分镜、估算与核验后完成 |
| 38秒草稿 | 已有14/12/12秒镜头；先检查，再压缩并复查。离线修订为28秒；真实模型可能删镜头或选择其他合规时间 |
| 缺信息 | 列出缺失项，不默认生成 |
| 无素材 | 改写查询或请求资料，不编造事实 |
| 工具失败一次 | 首次工具失败可重试或明确停止；成功结果保留 |
| 无依据80% | 实际规则失败后修正或明确未完成 |
| 仅1秒 | 旁白估算下限仍可能超限，不能通过虚报停留时长完成 |
| 首次检索为空 | 用更具体的特征词重新检索，下一工具结果可能不同 |

## 重复、恢复与故障

同 request_id 的请求和资料必须保持不变；修改主题、时长、规则或资料后点击“生成新 ID”。同 ID 改输入会返回 idempotency_conflict。用户编辑复查由服务自动创建新 ID。重复执行已检查成功的原请求会复用结果。

业务状态、草稿与历史保存在 `runtime/workbench.db`。网页任务列表在内存只保留最近100条；服务重启后原任务查询可能不存在，但可以提交相同原输入继续。浏览器保存最近请求，不保证未提交编辑在刷新后仍保留，请先复制或提交。完整证据及时导出。

如果模型不可用，检查 Ollama 是否启动、是否已 `ollama pull qwen2.5:7b-instruct`。CLI 需显式设置环境变量，网页默认配置本地端点；`.env.example` 不会被自动加载。远程服务需支持 Chat Completions JSON Schema，并使用自己的 HTTPS 服务及 Key。

## 时长和产品边界

每镜头计算 `max(停留秒数, ceil_0.1(有效字符数/风格语速+0.5))`，再加镜头之间转场。简洁/活泼/沉稳默认4/4.5/3字符每秒，普通句末标点与空白忽略，数字附近标点和正负号保留，英文按字符估算偏保守。真正制作前需配音和剪辑实测。

工具只核验对提供资料的忠实性，不证明真实世界产品资料无误。默认素材为合成 P01，不支持任何80%效果推断。项目不生成视频、不调用付费制作、不发布到平台。


## 实时调参工作台

1. 打开 http://127.0.0.1:8769/ 。桌面左侧查看输入预览和运行结果，右侧填写业务参数；窄屏先输入、后结果。
2. 调整目标时长；同步显示主题、时长上限、平台与风格。1–600 秒范围与原字段一致，保留 0.1 秒精度。预计总时长仍来自实际检查结果。
3. 拖动滑块或直接输入数值，只更新输入预览。点击原有运行按钮才执行 Agent；修改需求后仍须使用新请求编号。执行过程中快调滑块不可用。
4. 点击右上角“显示设置”，选择松绿 / 湖蓝 / 陶土 / 梅紫、浅色 / 深色、标准 / 大字、舒适 / 紧凑、关闭 / 轻微动效。设置即时生效，按 Esc 或“关闭”返回，焦点回到入口。
5. 显示偏好按项目保存在当前浏览器，刷新后恢复。“恢复默认显示”仅重置外观，不清空输入、请求编号、已保存任务或草稿。禁用存储时显示设置仍可临时生效。
6. 当前输入预览与上次运行结果分开：滑块改变不会重算费用、改动生效时间或刷新脚本检查。题二续跑、题四继续处理沿用原任务参数；新的需求应新建请求。

显示设置仅用于工作台，手册页面维持默认浅色。系统“减少动态效果”优先于轻微动效设置。每项目、每浏览器与每访问地址分别记忆偏好；localhost 与 127.0.0.1 是不同来源。
