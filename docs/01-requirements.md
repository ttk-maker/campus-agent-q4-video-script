# 用户、范围与验收

创作者输入主题、受众、平台、目标时长（秒）、风格，提供合成产品素材和品牌规则。输出标题、分镜、旁白/字幕、逐镜头估算、合计时长、素材 ID/事实 ID、风险、任务状态与版本。

| 编号 | 验收 | 判断 |
| --- | --- | --- |
| A01 | 正常生成 | 检索实际资料、生成脚本、当前版本时长/规则双检查通过 |
| A02 | 缺关键信息 | 列缺主题/受众/平台/时长/风格，不虚构默认输入 |
| A03 | 无素材 | 模型观察空结果后改查询或请求补充，不编造事实 |
| A04 | 工具失败 | 明确失败，保留已有产物，模型重试/停止；失败检查不当通过 |
| A05 | 超时长 | 观察估算后改分镜并复估；无法满足则明确未完成 |
| A06 | 事实追溯 | 每句旁白绑定实际检索来源 ID/事实 ID，拒绝不存在的效果数据 |

技术范围是可编辑脚本原型，不生成视频。目标时长解释为硬上限，不要求填满。时长为可复现启发式估算，不是假装真实音频测量：每镜头取展示时长与按语速计算的旁白时间的较大者，加镜头间转场。风格影响语速，平台是要求与品牌适用检查；不宣传自动掌握平台趋势。

事实安全采用保守抽取式组合：旁白需与已检索的某条事实原文一致（仅忽略汉字之间空白及有限句末陈述/感叹标点，保留英文词边界、句内标点、问号和单位上标），标题与画面说明来自品牌许可短语。模型可选择、排序、删减镜头并改变停留秒数；不能自由扩写产品效果。用户可编辑所有脚本字段，但编辑后的版本必须重新估算/核验后才就绪。未经支持的改写返回风险，而不依赖另一个模型猜测事实真伪。

该策略牺牲开放创意表达以提高本题可核验性。素材真实性本身由提供者负责；这里仅检查是否忠于提供且检索到的合成资料，不证明现实产品事实。禁止词规则能覆盖素材中本来就存在但品牌不允许的说法。
