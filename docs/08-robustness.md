# 基础、边缘与困难测试

可执行结果在 [tests/report.json](../examples/tests/report.json)，逐项输出 [tests/unittest.txt](../examples/tests/unittest.txt)；浏览器结果在 [browser/report.json](../examples/browser/report.json)。

| 层级 | 文件 | 关注点 |
| --- | --- | --- |
| 基础与核心，35项 | tests/test_script.py | 五必验、38→28、无依据80%、逐字段缺信息、空→空/有结果、所有业务工具失败、修改使检查失效、引用与原文、时长精度、重复、租约与步数上限 |
| 边缘与困难，16项 | tests/test_edges.py | 否定/额外收益/零宽字符、隐藏字幕字段、多来源对齐、语速变化、过期租约与旧 owner、失败重检、hash失效、提示注入动作守卫、模型格式失败、JSON Schema阶段选择、真正跨进程恢复 |
| HTTP，12项 | tests/test_web.py | 编辑后只检查不改写、超长编辑与模型后续修正、新请求版本、非法输入、Host/Origin/令牌、重启和幂等 |
| 浏览器，25项 | scripts/browser-smoke.cjs | 真实点击、下载、刷新、原文/时长编辑、风险展示、手动复查与模型修正区分、空检索、失败续跑、手机布局、文本转义和控制台 |

结构化输出限制模型动作格式，阶段工具集合由当前状态决定。它不是对业务答案的预填：submit_script 的镜头数、事实选择、顺序、文字与停留时间仍由模型输出；有失败检查时模型可提交修订或说明无法满足。工具层再次验证参数和完成事实，不能依赖模型自报。

确定性业务测试证明守卫；真实效果只能由 examples/real/ 与真实网页记录支持。对抗动作与恶意字符串测试不是大规模真实模型提示注入评测。时长是模型之外的可重现估算，不冒充配音实测。


追加边缘困难测试 `tests/test_hardening.py`：13 项，覆盖事实词边界/问号/分句/上标、时长精度、Trace终止持久化、旧策略复查和并发。本轮结果及真实模型失败/修复详见 [追加测试报告](09-hardening-round.md)。
